# IND-AS XBRL Workbench V3

The deployable V3 application is at the repository root. This file records the release namespace separately from prior IND-AS V1/V2 work.

V3 adds executable local preflight for machine-interpretable MCA business-rule text, dimensional NotAll checks, stronger mandatory/conditional checks, calculation and continuity checks, and an XML generation gate.

The MCA XBRL Validation Tool remains the final authority for complete validation and pre-scrutiny.
